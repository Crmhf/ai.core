# 智能驾驶系统

## 概述

智能驾驶系统(Intelligent Driving System)是自动驾驶技术的工程实现，集成了感知、决策、控制等多个子系统，为车辆提供不同程度的自动化驾驶能力。2024年，智能驾驶系统从L2级辅助驾驶向L3级有条件自动驾驶快速演进。

## 核心子系统

### 1. 感知系统

#### 多传感器融合

**前融合 vs 后融合**：
```
前融合(Deep Fusion)：
传感器原始数据 → 统一特征空间 → 联合推理
优势：信息损失少
挑战：数据同步、计算量大

后融合(Late Fusion)：
各传感器独立处理 → 结果融合
优势：模块化、易调试
劣势：信息损失
```

**主流方案**：BEV融合
- 将多摄像头数据转换到鸟瞰视角
- Transformer统一处理
- 时序信息融合

#### 目标检测与跟踪

**检测任务**：
- 车辆检测（类型、尺寸、朝向）
- 行人检测
- 骑行者检测
- 交通标志识别
- 红绿灯识别

**跟踪算法**：
- 卡尔曼滤波 + 匈牙利匹配
- DeepSORT
- 多目标跟踪(MOT)

### 2. 定位与建图

#### 多传感器融合定位

**紧耦合 vs 松耦合**：
```
松耦合：
各传感器独立定位 → 结果融合

紧耦合：
原始测量联合优化
精度更高，计算更复杂
```

#### SLAM技术

**视觉SLAM**：
- ORB-SLAM
- VINS-Fusion
- 成本低，依赖纹理

**激光SLAM**：
- LOAM
- LeGO-LOAM
- 精度高，成本高

#### 高精地图

**要素**：
- 车道线几何
- 车道拓扑
- 交通标志位置
- 坡度曲率

**更新**：
- 众包更新
- 实时建图

### 3. 决策系统

#### 行为决策

**状态机**：
```
状态：巡航、跟车、换道、超车、泊车
转移：条件触发状态切换
```

**行为树**：
- 层次化决策结构
- 模块化设计
- 易于扩展

#### 轨迹预测

**预测方法**：
- 基于物理模型
- 基于机器学习
- 基于交互建模

**输出**：
- 多模态轨迹（多个可能轨迹）
- 概率分布
- 预测时长：3-8秒

### 4. 规划系统

#### 全局路径规划
- A*算法
- Dijkstra算法
- 基于地图的最短路径

#### 局部轨迹规划

**采样方法**：
- Frenet坐标系采样
- 多项式轨迹
- 螺旋曲线

**优化方法**：
- 直接优化
- 模型预测控制(MPC)
- 二次规划(QP)

**约束条件**：
- 避障约束
- 运动学约束
- 舒适性约束
- 交通法规约束

### 5. 控制系统

#### 横向控制

**纯追踪控制**：
```
计算目标曲率：
κ = 2y / L²
其中y为横向偏差，L为前瞻距离
```

**Stanley控制**：
- 考虑航向误差和横向误差
- 非线性反馈

**MPC控制**：
- 预测未来轨迹
- 滚动优化
- 处理约束

#### 纵向控制

**ACC控制**：
- 定速巡航
- 自适应巡航
- 安全距离保持

**AEB控制**：
- 紧急制动
- 碰撞避免

## 功能实现

### 1. 自适应巡航(ACC)

**功能**：
- 自动保持设定速度
- 自动调整车距
- 跟车启停

**传感器**：毫米波雷达 + 摄像头

### 2. 车道保持(LKA/LCC)

**功能**：
- 车道线检测
- 自动转向保持居中
- 车道偏离预警

**技术**：视觉车道线检测 + 横向控制

### 3. 自动变道(ALC)

**触发条件**：
- 拨杆变道
- 导航变道（高速/匝道）
- 超车变道

**安全确认**：
- 盲区监测
- 后车速度判断
- 安全距离确认

### 4. 导航辅助驾驶(NOA/NGP/NOP)

**功能**：
- 自动进出匝道
- 自动超车
- 自动调速
- 按导航路径行驶

**场景**：
- 高速NOA（已普及）
- 城市NOA（快速发展）

### 5. 自动泊车

**功能演进**：
```
APA（自动泊车辅助）
  ↓
RPA（遥控泊车）
  ↓
HPA（记忆泊车）
  ↓
AVP（代客泊车）- 目标
```

**技术**：
- 环视视觉
- 超声波雷达
- 车位识别
- 路径规划
