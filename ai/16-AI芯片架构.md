# AI芯片架构

## 概述

AI芯片是专门为人工智能计算任务设计的处理器，相比通用CPU，在深度学习推理和训练任务上具有数量级的性能提升和能效优势。2024年是AI PC元年，各大厂商密集推出集成NPU的AI处理器。

## AI芯片分类

### 按应用场景分类

| 类型 | 特点 | 代表产品 |
|-----|------|---------|
| **云端训练芯片** | 高算力、高内存带宽 | NVIDIA H100、Google TPU |
| **云端推理芯片** | 高能效比、低延迟 | NVIDIA T4、AWS Inferentia |
| **边缘推理芯片** | 低功耗、小尺寸 | 高通骁龙、苹果A系列 |
| **终端AI芯片** | 超低功耗、Always-on | 智能安防芯片、TWS芯片 |

### 按架构类型分类

#### 1. GPU（图形处理器）
**特点**：
- 大规模并行计算
- 成熟的软件生态（CUDA）
- 适合训练和大规模推理

**代表**：NVIDIA A100/H100、AMD MI300

#### 2. TPU（张量处理器）
**特点**：
- Google专为深度学习设计
- 矩阵运算优化
- 高能效比

**代表**：TPU v4/v5

#### 3. NPU（神经网络处理器）
**特点**：
- 专用AI加速
- 低功耗设计
- 集成在手机、PC处理器中

**代表**：苹果Neural Engine、高通Hexagon、Intel NPU

#### 4. FPGA（可编程逻辑门阵列）
**特点**：
- 可编程、灵活性高
- 延迟低
- 适合算法快速迭代

**代表**：Xilinx Versal、Intel Agilex

#### 5. ASIC（专用集成电路）
**特点**：
- 针对特定算法优化
- 能效比最高
- 开发成本高

**代表**：Google TPU、寒武纪MLU

## 核心计算单元

### 1. 矩阵乘法单元（Matrix Multiply Unit）

深度学习核心运算是矩阵乘法：
```
C = A × B
其中A、B、C是大规模矩阵
```

**脉动阵列(Systolic Array)**：
```
数据流动方式：
┌───┬───┬───┐
│PE │PE │PE │  ← 权重流动
├───┼───┼───┤
│PE │PE │PE │
├───┼───┼───┤
│PE │PE │PE │
└───┴───┴───┘
   ↑
 激活值流动

每个PE(Processing Element)执行乘加运算
数据在阵列中流动，最大化数据复用
```

### 2. 向量处理单元

**SIMD架构**：
- 单指令多数据
- 向量化加速
- 适合激活函数等操作

### 3. 专用功能单元

| 单元 | 功能 | 应用 |
|-----|------|------|
| 卷积加速器 | 滑动窗口计算 | CNN |
| LSTM加速器 | 门控计算 | RNN |
| Attention引擎 | 注意力计算 | Transformer |
| 激活单元 | ReLU、Sigmoid等 | 通用 |

## 内存架构

### 内存墙问题

**挑战**：
- 计算速度增长快于内存带宽
- 数据搬运成为瓶颈
- 功耗占比高

### 解决方案

#### 1. 高带宽内存(HBM)
```
HBM2E：460 GB/s
HBM3：819 GB/s
HBM3E：1.2 TB/s+

3D堆叠技术：
多层DRAM芯片垂直堆叠
通过硅通孔(TSV)连接
```

#### 2. 近内存计算
```
传统架构：
数据：内存 → CPU/GPU → 计算

近内存架构：
计算单元靠近或集成在内存中
减少数据搬运距离
```

#### 3. 片上缓存优化
- 多级缓存架构
- 数据流优化
- 数据复用最大化

### 内存层次

```
┌─────────────────┐
│   寄存器文件     │  ← 最快，容量最小
├─────────────────┤
│   L1/L2缓存     │
├─────────────────┤
│   共享内存/SRAM  │
├─────────────────┤
│   HBM/显存      │
├─────────────────┤
│   系统内存      │  ← 最慢，容量最大
└─────────────────┘
```

## 数据流架构

### 1. 权重静止(Weight Stationary)

**策略**：
- 将权重保存在PE寄存器中
- 最大化权重复用
- 适合层内计算

**适用**：权重较小的网络层

### 2. 输出静止(Output Stationary)

**策略**：
- 累加部分和在PE中
- 减少部分和写入内存
- 最大化输出复用

**适用**：卷积层计算

### 3. 行静止(Row Stationary)

**策略**：
- 平衡权重和激活值复用
- 适应不同网络结构

**代表**：Eyeriss架构

### 4. 无本地重用(No Local Reuse)

**策略**：
- 完全依赖全局缓存
- 简单规则的数据流
- 适合大规模并行

## 发展趋势

### 1. 存算一体
```
传统架构：
计算和存储分离，数据搬运耗能大

存算一体：
在存储单元中进行计算
消除数据搬运瓶颈
大幅提升能效
```

### 2. 光计算
- 利用光子进行计算
- 超高带宽、低延迟
- 低功耗

### 3. 神经形态芯片
- 模拟大脑神经元结构
- 事件驱动、异步处理
- 超低功耗

### 4. Chiplet架构
- 模块化设计
- 不同工艺混搭
- 灵活组合、降低成本

### 5. 超大模型训练优化
- 稀疏计算加速
- 混合精度训练
- 分布式训练优化
