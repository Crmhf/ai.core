# 生成式AI与大模型

## 生成式AI概述

生成式AI（Generative AI）是一类能够创造新内容的人工智能系统，包括文本、图像、音频、视频、代码等。与传统的判别式AI不同，生成式AI不仅学习数据的特征，还学习数据的分布，从而能够生成与训练数据相似的新样本。

### 生成式AI vs 判别式AI

| 特性 | 判别式AI | 生成式AI |
|-----|---------|---------|
| 学习目标 | P(Y\|X) | P(X) 或 P(X,Y) |
| 主要任务 | 分类、回归 | 生成、创造 |
| 输出 | 标签或数值 | 新样本 |
| 典型模型 | SVM、逻辑回归 | GAN、VAE、扩散模型 |

## 生成式AI的技术基础

### 1. 变分自编码器（VAE）

VAE通过编码器-解码器架构学习数据的潜在表示。

**核心思想**：
```
编码器：q(z|x) - 将数据映射到潜在空间
解码器：p(x|z) - 从潜在空间重构数据
目标：最大化证据下界（ELBO）
```

**损失函数**：
```
L = E[log p(x|z)] - KL(q(z|x) || p(z))
    ↑重构损失          ↑KL散度（正则化）
```

### 2. 生成对抗网络（GAN）

由生成器G和判别器D组成的对抗系统。

**训练目标**：
```
min_G max_D V(D,G) = E[log D(x)] + E[log(1 - D(G(z)))]
```

**GAN变体**：
- DCGAN：深度卷积GAN
- CGAN：条件GAN
- StyleGAN：风格控制的图像生成
- CycleGAN：无配对图像翻译

### 3. 自回归模型

基于序列的生成方式，逐个生成元素。

**代表模型**：
- PixelCNN/RNN：图像生成
- GPT系列：文本生成
- WaveNet：音频生成

### 4. 扩散模型（Diffusion Model）

当前图像生成的主流技术。

**前向过程（加噪）**：
```
q(xₜ|xₜ₋₁) = N(xₜ; √(1-βₜ)xₜ₋₁, βₜI)
```

**反向过程（去噪）**：
```
p_θ(xₜ₋₁|xₜ) = N(xₜ₋₁; μ_θ(xₜ,t), Σ_θ(xₜ,t))
```

**代表模型**：
- DDPM：去噪扩散概率模型
- Stable Diffusion：潜空间扩散模型
- DALL-E 2/3：OpenAI的图像生成模型
- Midjourney：艺术风格图像生成

## 大语言模型（LLM）

### 什么是大语言模型

大语言模型（Large Language Model）是基于Transformer架构的神经网络，通过在海量文本数据上进行自监督学习，获得强大的语言理解和生成能力。

### 规模定律（Scaling Laws）

模型性能随以下因素提升而提升：
- **模型参数数量**
- **训练数据量**
- **计算量（FLOPs）**

```
性能 ∝ (参数)^α · (数据)^β · (计算)^γ
```

### 主要大模型演进

| 时间 | 模型 | 参数量 | 特点 |
|-----|------|-------|------|
| 2018 | GPT-1 | 117M | 首个生成式预训练模型 |
| 2018 | BERT | 340M | 双向编码器，理解能力强 |
| 2019 | GPT-2 | 1.5B | 零样本学习能力 |
| 2020 | GPT-3 | 175B | 涌现能力，上下文学习 |
| 2022 | ChatGPT | - | RLHF对齐人类偏好 |
| 2023 | GPT-4 | - | 多模态，推理能力强 |
| 2023 | Claude | - | 长上下文，安全性高 |
| 2024 | GPT-4o | - | 原生多模态，实时交互 |

### 核心技术

#### 预训练（Pre-training）

**自监督学习**：
- 语言建模：预测下一个词
- 掩码语言建模：预测被遮盖的词
- 去噪自编码：重构被扰动的输入

**数据规模**：
- 训练数据通常达到TB级别
- 包含网页、书籍、论文、代码等

#### 指令微调（Instruction Tuning）

使用(指令, 输入, 输出)格式的数据对模型进行微调，使其能够遵循人类指令。

**代表数据集**：
- FLAN
- Alpaca
- Dolly

#### RLHF（人类反馈强化学习）

通过人类偏好反馈训练奖励模型，再用强化学习优化策略。

**流程**：
```
1. 收集比较数据（人类标注哪个回答更好）
2. 训练奖励模型
3. 使用PPO等算法优化策略
```

#### 上下文学习（In-Context Learning）

模型通过提示（Prompt）中的示例学习新任务，无需参数更新。

```
示例：
输入：这部电影太精彩了 -> 正面
输入：完全浪费时间 -> 负面
输入：特效很棒但剧情一般 ->
```

### 提示工程（Prompt Engineering）

设计有效的输入提示以获得更好的模型输出。

**常用技术**：
- Zero-shot：直接描述任务
- Few-shot：提供示例
- Chain-of-Thought：引导逐步推理
- ReAct：推理与行动结合

## 多模态大模型

### 什么是多模态

能够同时处理和理解多种模态（文本、图像、音频、视频）的AI系统。

### 典型架构

**编码器-解码器架构**：
```
图像编码器（ViT）
        ↓
    融合模块 ← 文本编码器
        ↓
    多模态解码器
```

### 代表模型

| 模型 | 发布方 | 特点 |
|-----|-------|------|
| CLIP | OpenAI | 图文对齐，跨模态检索 |
| DALL-E | OpenAI | 文本生成图像 |
| GPT-4V | OpenAI | 视觉理解能力 |
| Gemini | Google | 原生多模态 |
| LLaVA | 开源 | 视觉指令微调 |

## 大模型的挑战

### 技术挑战
1. **幻觉（Hallucination）**：生成虚假或错误信息
2. **上下文限制**：有限的上下文窗口
3. **推理能力**：复杂逻辑推理仍有局限
4. **计算成本**：训练和推理成本高昂

### 伦理挑战
1. **偏见与公平性**：训练数据中的偏见
2. **隐私保护**：数据泄露风险
3. **滥用风险**：生成虚假信息、恶意内容
4. **版权问题**：训练数据和生成内容的版权

### 解决方案
- RAG（检索增强生成）
- 模型对齐技术
- 安全护栏
- 可解释性研究

- **剪枝（Pruning）**：移除不重要的权重
- **蒸馏（Distillation）**：小模型学习大模型
- **投机解码（Speculative Decoding）**：加速推理
