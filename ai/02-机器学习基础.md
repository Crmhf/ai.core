# 机器学习基础

## 什么是机器学习

机器学习（Machine Learning，ML）是人工智能的一个核心子领域，它使计算机系统能够从数据中自动学习和改进，而无需进行明确的编程。机器学习的本质是**通过算法让计算机从经验中学习规律，并利用这些规律对未知数据进行预测或决策**。

### 经典定义

> "如果一个计算机程序在某类任务T上的性能P，随着经验E的增加而提高，那么它就被认为是从经验E中关于任务T和性能度量P进行学习。" —— Tom Mitchell

## 机器学习的主要类型

### 1. 监督学习（Supervised Learning）
使用带有标签的训练数据进行学习，建立输入到输出的映射关系。

**常见算法**：
- 线性回归（Linear Regression）
- 逻辑回归（Logistic Regression）
- 决策树（Decision Tree）
- 支持向量机（SVM）
- 随机森林（Random Forest）
- 神经网络

**应用场景**：
- 房价预测
- 垃圾邮件分类
- 疾病诊断
- 信用评分

### 2. 无监督学习（Unsupervised Learning）
处理没有标签的数据，发现数据中的内在结构和模式。

**常见算法**：
- K-means聚类
- 层次聚类
- 主成分分析（PCA）
- 自编码器（Autoencoder）
- 高斯混合模型

**应用场景**：
- 客户分群
- 异常检测
- 降维可视化
- 推荐系统

### 3. 强化学习（Reinforcement Learning）
通过与环境交互，学习最优行为策略以最大化累积奖励。

**核心概念**：
- 智能体（Agent）
- 环境（Environment）
- 状态（State）
- 动作（Action）
- 奖励（Reward）

**常见算法**：
- Q-Learning
- SARSA
- 深度Q网络（DQN）
- 策略梯度方法
- Actor-Critic

**应用场景**：
- 游戏AI（AlphaGo、OpenAI Five）
- 机器人控制
- 自动驾驶
- 资源调度

## 机器学习工作流程

```
┌─────────────┐    ┌─────────────┐    ┌─────────────┐
│  数据收集    │ -> │  数据预处理  │ -> │  特征工程   │
└─────────────┘    └─────────────┘    └─────────────┘
                                              |
                                              v
┌─────────────┐    ┌─────────────┐    ┌─────────────┐
│  模型部署    │ <- │  模型评估    │ <- │  模型训练   │
└─────────────┘    └─────────────┘    └─────────────┘
```

### 1. 数据收集
- 确定数据来源
- 数据采集和存储
- 数据质量检查

### 2. 数据预处理
- 数据清洗（处理缺失值、异常值）
- 数据标准化/归一化
- 数据类型转换
- 数据集划分（训练集、验证集、测试集）

### 3. 特征工程
- 特征选择
- 特征提取
- 特征构造
- 特征编码

### 4. 模型训练
- 选择算法
- 设置超参数
- 训练模型
- 损失函数优化

### 5. 模型评估
- 性能指标计算
- 交叉验证
- 过拟合/欠拟合诊断

### 6. 模型部署
- 模型导出
- 服务化部署
- 监控和维护

## 核心概念详解

### 损失函数（Loss Function）
衡量模型预测与真实值之间差异的函数。

**常见损失函数**：
- **均方误差（MSE）**：用于回归任务
  ```
  MSE = (1/n) * Σ(y_true - y_pred)²
  ```
- **交叉熵损失（Cross-Entropy）**：用于分类任务
  ```
  CE = -Σ y_true * log(y_pred)
  ```
- **平均绝对误差（MAE）**：对异常值更鲁棒

### 优化算法
用于最小化损失函数的算法。

**梯度下降变体**：
- **批量梯度下降（BGD）**：使用全部数据
- **随机梯度下降（SGD）**：使用单个样本
- **小批量梯度下降（Mini-batch GD）**：使用小批量数据
- **Adam**：自适应学习率优化器
- **RMSprop**：适合处理非平稳目标

### 过拟合与欠拟合

#### 过拟合（Overfitting）
模型在训练数据上表现很好，但在新数据上表现差。

**解决方案**：
- 增加训练数据
- 正则化（L1/L2）
- Dropout
- 早停（Early Stopping）
- 数据增强

#### 欠拟合（Underfitting）
模型过于简单，无法捕捉数据中的模式。

**解决方案**：
- 增加模型复杂度
- 添加更多特征
- 减少正则化
- 训练更长时间

### 模型评估指标

#### 分类任务
- **准确率（Accuracy）**：正确预测的比例
- **精确率（Precision）**：正例预测中真正为正的比例
- **召回率（Recall）**：真正为正例中被正确预测的比例
- **F1分数**：精确率和召回率的调和平均
- **ROC-AUC**：受试者工作特征曲线下面积

#### 回归任务
- **均方误差（MSE）**
- **均方根误差（RMSE）**
- **平均绝对误差（MAE）**
- **R²分数**：解释方差的比例

## 常用的机器学习框架

| 框架 | 特点 | 适用场景 |

## 学习路径建议

1. **数学基础**：线性代数、概率论、微积分
2. **编程技能**：Python、NumPy、Pandas
3. **基础算法**：监督学习、无监督学习
4. **实践项目**：Kaggle竞赛、实际业务问题
5. **深度学习**：神经网络、CNN、RNN
6. **高级主题**：强化学习、迁移学习、联邦学习
