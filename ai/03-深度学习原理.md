# 深度学习原理

## 什么是深度学习

深度学习（Deep Learning）是机器学习的一个子领域，基于**多层人工神经网络**进行学习。其核心思想是通过多层次的非线性变换，从数据中自动学习层次化的特征表示。

### 核心公式

**深度学习 = 表示学习 + 决策（预测）学习**

### 与传统机器学习的区别

| 特性 | 传统机器学习 | 深度学习 |
|-----|-------------|---------|
| 特征工程 | 需要人工设计特征 | 自动学习特征表示 |
| 数据需求 | 较小的数据集即可 | 需要大量数据 |
| 计算资源 | CPU即可 | 需要GPU加速 |
| 可解释性 | 相对较好 | 黑盒特性明显 |
| 应用场景 | 结构化数据 | 图像、语音、文本等复杂数据 |

## 神经网络基础

### 神经元模型

人工神经元是神经网络的基本计算单元，模拟生物神经元的工作方式：

```
输入: x₁, x₂, ..., xₙ
权重: w₁, w₂, ..., wₙ
偏置: b
输出: y = f(Σ(wᵢ × xᵢ) + b)
```

其中 f 是**激活函数**，引入非线性因素。

### 激活函数

激活函数决定神经元是否激活以及输出什么值。

#### Sigmoid
```
σ(x) = 1 / (1 + e^(-x))
```
- 输出范围：(0, 1)
- 适合二分类输出
- 缺点：梯度消失问题

#### Tanh
```
tanh(x) = (e^x - e^(-x)) / (e^x + e^(-x))
```
- 输出范围：(-1, 1)
- 零中心化，收敛更快

#### ReLU（Rectified Linear Unit）
```
ReLU(x) = max(0, x)
```
- 计算简单，收敛快
- 缓解梯度消失
- 可能出现"神经元死亡"

#### Leaky ReLU
```
LeakyReLU(x) = max(αx, x)  (α通常取0.01)
```
- 解决ReLU的神经元死亡问题

#### Softmax
```
Softmax(xᵢ) = e^(xᵢ) / Σe^(xⱼ)
```
- 用于多分类输出层
- 输出概率分布

## 深度神经网络架构

### 全连接网络（Fully Connected Network）

每一层神经元与下一层所有神经元连接。

```
输入层 -> 隐藏层1 -> 隐藏层2 -> ... -> 输出层
```

### 前向传播（Forward Propagation）

数据从输入层流向输出层的计算过程：

```
z^[l] = W^[l] × a^[l-1] + b^[l]
a^[l] = g(z^[l])
```

其中：
- z^[l]：第l层的线性变换结果
- W^[l]：权重矩阵
- b^[l]：偏置向量
- g：激活函数
- a^[l]：第l层的激活值

### 反向传播（Backpropagation）

计算梯度并更新权重的核心算法：

1. **计算输出层误差**：
   ```
   δ^[L] = ∇ₐC ⊙ g'(z^[L])
   ```

2. **反向传播误差**：
   ```
   δ^[l] = ((W^[l+1])ᵀ × δ^[l+1]) ⊙ g'(z^[l])
   ```

3. **计算梯度**：
   ```
   ∂C/∂W^[l] = δ^[l] × (a^[l-1])ᵀ
   ∂C/∂b^[l] = δ^[l]
   ```

4. **更新权重**：
   ```
   W^[l] := W^[l] - η × ∂C/∂W^[l]
   b^[l] := b^[l] - η × ∂C/∂b^[l]
   ```

## 训练优化技术

### 批量归一化（Batch Normalization）

对每一层的输入进行归一化，加速训练：

```
x̂ = (x - μ) / √(σ² + ε)
y = γ × x̂ + β
```

优点：
- 允许使用更大的学习率
- 减少对初始化的依赖
- 具有正则化效果

### 权重初始化

#### Xavier/Glorot初始化
```
W ~ Uniform(-√(6/(n_in + n_out)), √(6/(n_in + n_out)))
```
适用于Sigmoid和Tanh激活函数

#### He初始化
```
W ~ N(0, √(2/n_in))
```
适用于ReLU激活函数

### 正则化技术

#### Dropout
训练时随机丢弃一部分神经元，防止过拟合：
```
训练时：以概率p随机将神经元输出置为0
测试时：所有神经元参与，输出乘以p
```

#### L2正则化（权重衰减）
```
J(θ) = L(θ) + λ × Σθ²
```

#### L1正则化
```
J(θ) = L(θ) + λ × Σ|θ|
```
产生稀疏权重

### 学习率调度

- **学习率衰减**：随时间降低学习率
- **自适应学习率**：AdaGrad、RMSprop、Adam
- **Warmup**：训练初期逐渐增加学习率

## 常见的深度学习网络类型

### 卷积神经网络（CNN）
专门用于处理网格结构数据（如图像）。

**核心组件**：
- 卷积层（提取局部特征）
- 池化层（降维、平移不变性）
- 全连接层（分类）

**经典架构**：
- LeNet（1998）
- AlexNet（2012）
- VGGNet（2014）
- ResNet（2015）
- EfficientNet（2019）

### 循环神经网络（RNN）
用于处理序列数据，具有记忆功能。

**变体**：
- **LSTM**（长短期记忆网络）：解决长序列依赖问题
- **GRU**（门控循环单元）：LSTM的简化版本
- **双向RNN**：同时考虑过去和未来的信息

### Transformer
基于注意力机制的序列转换模型，当前主流架构。

**核心组件**：
- 自注意力机制（Self-Attention）
- 多头注意力（Multi-Head Attention）
- 位置编码（Positional Encoding）
- 前馈网络（Feed-Forward Network）

**应用**：
- BERT（双向编码器）
- GPT（生成式预训练）
- T5（文本到文本转换）
- Vision Transformer（ViT）

### 生成对抗网络（GAN）
由生成器和判别器组成的对抗系统。

```
生成器G：学习生成假样本
判别器D：区分真实样本和生成样本

目标函数：
min_G max_D V(D,G) = E[log D(x)] + E[log(1 - D(G(z)))]
```

## 深度学习的挑战与趋势

### 当前挑战
1. **数据需求**：需要大量标注数据
2. **计算成本**：训练大模型需要昂贵算力
3. **可解释性**：黑盒特性限制应用
4. **泛化能力**：分布外数据表现不稳定
5. **安全性**：对抗样本攻击

### 发展趋势
1. **大模型**：参数规模持续增长
2. **多模态**：融合文本、图像、音频
3. **高效AI**：模型压缩、知识蒸馏
4. **神经架构搜索（NAS）**：自动化网络设计
5. **可解释AI**：提高模型透明度
