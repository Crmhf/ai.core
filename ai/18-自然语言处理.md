# 自然语言处理

## 概述

自然语言处理（Natural Language Processing，NLP）是人工智能的核心领域之一，研究如何让计算机理解、解释和生成人类语言。近年来，以Transformer和大语言模型为代表的技术突破，使NLP进入了新的发展阶段。

## NLP主要任务

### 1. 文本分类

#### 情感分析
```
输入：
"这部电影太精彩了！"

输出：
正面情感（置信度：0.95）
```

**应用场景**：
- 产品评论分析
- 社交媒体监测
- 品牌声誉管理

#### 主题分类
- 新闻分类（体育、政治、科技等）
- 邮件自动归类
- 文档管理

#### 意图识别
```
输入：
"明天北京天气怎么样？"

输出：
意图：查询天气
实体：时间=明天，地点=北京
```

## 核心技术演进

### 1. 传统方法（2013年前）

#### 基于规则
- 正则表达式
- 专家系统
- 语法规则

#### 基于统计
- 隐马尔可夫模型(HMM)
- 条件随机场(CRF)
- 朴素贝叶斯
- 支持向量机

### 2. 神经网络时代（2013-2017）

#### 词嵌入(Word Embedding)
**Word2Vec**：
```
Skip-gram模型：
输入：中心词
输出：上下文词

目标：学习词向量，使得语义相似的词在向量空间相近
```

**GloVe**：
- 基于全局词-词共现矩阵
- 融合全局统计信息和局部上下文

#### RNN/LSTM/GRU
```
序列建模：
h_t = f(h_{t-1}, x_t)

优势：
- 处理变长序列
- 考虑上下文

局限：
- 长距离依赖困难
- 难以并行化
```

### 3. Transformer时代（2017至今）

#### Transformer架构
```
核心创新：
- 自注意力机制（Self-Attention）
- 完全并行化
- 长距离依赖建模

Encoder：
- 双向编码
- 适合理解任务
- 代表：BERT

Decoder：
- 自回归生成
- 适合生成任务
- 代表：GPT

Encoder-Decoder：
- 序列到序列
- 代表：T5、BART
```

#### 自注意力机制
```
计算步骤：
1. Q = XW^Q, K = XW^K, V = XW^V
2. Scores = QK^T / √d_k
3. Weights = Softmax(Scores)
4. Output = Weights × V

复杂度：O(n²d)
n: 序列长度
d: 特征维度
```

#### BERT（2018）
```
预训练任务：
1. Masked Language Model（MLM）
   - 遮盖15%的token，预测原词
   - 双向上下文理解

2. Next Sentence Prediction（NSP）
   - 判断句子对关系
   - 理解句子间逻辑

影响：
- 开启预训练+微调范式
- 刷新多项NLP基准
```

#### GPT系列
```
GPT-1（2018）：
- 生成式预训练
- 117M参数

GPT-2（2019）：
- 15亿参数
- 零样本能力

GPT-3（2020）：
- 1750亿参数
- 涌现能力
- 上下文学习

GPT-4（2023）：
- 多模态能力
- 推理能力提升
```

## 大语言模型技术

### 1. 预训练

#### 数据准备
```
数据来源：
- 网页（Common Crawl）
- 书籍（BooksCorpus）
- 维基百科
- 代码（GitHub）
- 学术论文

数据处理：
- 去重
- 质量过滤
- 隐私脱敏
- 分词（Tokenization）
```

#### 训练目标
```
自回归语言建模：
P(x) = ∏ P(x_i | x_{<i})

目标：最大化训练数据似然
loss = -Σ log P(x_i | x_{<i})
```

### 2. 指令微调(Instruction Tuning)

```
数据格式：
{
  "instruction": "将中文翻译成英文",
  "input": "今天天气很好",
  "output": "The weather is nice today"
}

目的：
- 使模型理解并遵循指令
- 提升零样本能力
- 对齐人类使用方式
```

### 3. RLHF（人类反馈强化学习）

```
三阶段流程：

1. 监督微调(SFT)
   - 高质量指令数据
   - 有监督训练

2. 奖励模型训练
   - 收集人类偏好数据
   - 训练奖励模型预测人类偏好

3. 强化学习优化
   - PPO算法
   - 最大化奖励模型分数
   - KL散度约束
```

### 4. 上下文学习(In-Context Learning)

```
零样本学习：
"将以下中文翻译成英文：你好"

少样本学习：
"中文：你好 -> 英文：Hello
 中文：世界 -> 英文：World
 中文：人工智能 -> 英文："

思维链(Chain-of-Thought)：
"问题：一个农场有35只鸡...
 让我们一步步思考：
 1. ...
 2. ...
 答案："
```

## 提示工程(Prompt Engineering)

### 基础技巧

#### 零样本提示
```
简单直接描述任务
```

#### 少样本提示
```
提供示例，引导模型输出格式
```

#### 角色提示
```
"你是一位专业的翻译家..."
```

### 高级技巧

#### Chain-of-Thought
```
引导模型逐步推理
"让我们一步步思考..."
```

#### Self-Consistency
```
多次采样，选择最一致的答案
```

#### ReAct
```
推理(Reasoning) + 行动(Acting)结合
Thought -> Action -> Observation -> ...
```

#### Tree of Thoughts
```
探索多个推理路径
评估并选择最佳路径
```

## 挑战与前沿

### 当前挑战

#### 幻觉(Hallucination)
```
问题：生成看似合理但实际错误的内容

缓解：
- RAG（检索增强生成）
- 事实核查
- 置信度估计
```

#### 偏见与公平性
```
问题：训练数据中的偏见被模型学习

解决：
- 数据清洗
- 公平性约束
- 偏见检测
```

#### 长文本处理
```
问题：Transformer的O(n²)复杂度限制

方案：
- 稀疏注意力
- 线性注意力
- 分块处理
- 长上下文模型（100K+ tokens）
```
