# 计算机视觉

## 概述

计算机视觉（Computer Vision，CV）是人工智能的重要分支，研究如何让计算机从图像或视频中获取高级理解。从图像分类到目标检测，从人脸识别到自动驾驶，计算机视觉技术已广泛应用于各行各业。

## 核心任务

### 1. 图像分类

#### 任务定义
```
输入：图像
输出：类别标签（一个或多个）

示例：
输入：猫的图片
输出："猫"（置信度：0.98）
```

#### 经典数据集
| 数据集 | 类别数 | 图像数 | 用途 |
|-------|-------|-------|------|
| MNIST | 10 | 70,000 | 手写数字识别 |
| CIFAR-10 | 10 | 60,000 | 基础分类 |
| ImageNet | 1,000 | 140万 | 大规模分类 |
| COCO | 80 | 33万 | 目标检测、分割 |

#### 经典架构演进
```
2012: AlexNet - 深度学习开端
2014: VGGNet - 小卷积核堆叠
2014: GoogLeNet/Inception - 多尺度特征
2015: ResNet - 残差连接，可训练152+层
2016: DenseNet - 密集连接
2017: SqueezeNet - 轻量化
2019: EfficientNet - 复合缩放
2020: Vision Transformer - Transformer进军视觉
```

### 2. 目标检测

#### 任务定义
```
输入：图像
输出：目标边界框 + 类别 + 置信度

示例：
[{"bbox": [100, 200, 300, 400], "class": "person", "score": 0.95}, ...]
```

#### 两阶段检测器
**R-CNN系列**：
```
R-CNN（2014）：
1. Selective Search提取候选框
2. CNN提取特征
3. SVM分类
4. 回归精修边界框

Fast R-CNN（2015）：
- 共享卷积特征
- ROI Pooling
- 多任务损失

Faster R-CNN（2015）：
- RPN（Region Proposal Network）
- 端到端训练
```

#### 单阶段检测器
**YOLO系列**：
```
YOLOv1-v3（Joseph Redmon）
YOLOv4（2020, Alexey Bochkovskiy）
YOLOv5-v8（Ultralytics）
YOLOv9-v10（2024）

特点：
- 单次前向传播
- 速度快（实时）
- 精度不断提升
```

**SSD（Single Shot MultiBox Detector）**：
- 多尺度特征图检测
- 不同尺度的先验框

#### 无锚框检测器
```
CenterNet：
- 中心点检测
- 回归目标尺寸

FCOS：
- 逐像素预测
- 无需预定义锚框

DETR：
- Transformer-based
- 全局注意力
```

### 3. 图像分割

#### 语义分割
```
为每个像素分配类别标签

应用：
- 自动驾驶（可行驶区域）
- 医学影像（器官分割）
- 卫星图像（土地利用）
```

**经典架构**：
```
FCN（2015）：首个端到端分割网络
U-Net（2015）：编码器-解码器+跳跃连接
DeepLab系列：空洞卷积+CRF
PSPNet：金字塔池化
SegFormer：Transformer+MLP解码器
```

#### 实例分割
```
区分同类别的不同实例

应用：
- 人机交互
- 图像编辑
- 机器人抓取
```

**Mask R-CNN**：
- 在Faster R-CNN基础上添加分割分支
- ROI Align代替ROI Pooling

#### 全景分割
语义分割 + 实例分割的统一

### 4. 目标跟踪

#### 单目标跟踪
```
给定初始目标位置，在后续帧中持续跟踪

方法：
- 相关滤波
- Siamese网络
- 检测+匹配
```

#### 多目标跟踪(MOT)
```
同时跟踪多个目标，保持ID一致性

方法：
- SORT：卡尔曼滤波+匈牙利算法
- DeepSORT：外观特征+运动信息
- ByteTrack：基于检测框的关联
```

### 5. 人脸识别

#### 技术流程
```
1. 人脸检测（MTCNN、RetinaFace）
2. 人脸对齐（关键点检测）
3. 特征提取（FaceNet、ArcFace）
4. 特征比对（余弦相似度）
```

#### 关键指标
- 识别准确率
- 误识率(FAR)
- 拒识率(FRR)

### 6. 姿态估计

#### 2D姿态估计
```
检测人体关键点（关节位置）

代表方法：
- OpenPose
- AlphaPose
- HRNet
```

#### 3D姿态估计
- 单目3D姿态
- 多视角融合
- 深度相机

### 7. 图像生成

#### 生成对抗网络(GAN)
```
StyleGAN：高分辨率人脸生成
```

#### 扩散模型

## 核心技术详解

### 卷积神经网络(CNN)

#### 卷积操作
```
输出特征图[i,j] = ΣΣ 输入特征图[i+m, j+n] × 卷积核[m, n]

参数：
- 卷积核大小（3×3, 5×5, 7×7）
- 步长（stride）
- 填充（padding）
- 通道数
```

#### 池化操作
```
最大池化：取窗口内最大值
平均池化：取窗口内平均值

作用：
- 降维
- 平移不变性
- 扩大感受野
```

#### 现代卷积变体
```
空洞卷积（Dilated Conv）：
- 扩大感受野不增加参数
- 语义分割常用

可变形卷积（Deformable Conv）：
- 自适应采样位置
- 适应目标形变

深度可分离卷积（Depthwise Separable）：
- 减少参数量
- MobileNet核心
```

### Transformer在视觉中的应用

#### Vision Transformer(ViT)
```
核心思想：
- 将图像分割为patch
- 将patch作为序列输入Transformer
- 全局注意力建模

流程：
图像 → Patch Embedding → Position Embedding → Transformer Encoder → MLP Head
```

#### 改进架构
```
Swin Transformer：
- 层次化架构
- 移动窗口注意力
- 计算效率优化

DeiT：
- 数据高效训练
- 知识蒸馏

PVT：
- 金字塔Vision Transformer
- 密集预测任务
```

### 注意力机制

#### 自注意力
```
输入：Query(Q), Key(K), Value(V)
输出：Softmax(QK^T/√d)V

在视觉中的应用：
- Non-local Neural Networks
- Self-Attention in GANs
- Transformer-based检测/分割
```

#### 通道注意力
```
SE-Net（Squeeze-and-Excitation）：
- 学习通道重要性
- 自适应特征重标定

CBAM：
- 通道+空间双重注意力
```
