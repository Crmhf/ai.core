# 神经网络详解

## 神经网络概述

神经网络（Neural Networks）是一种受生物神经系统启发的计算模型，由大量相互连接的人工神经元组成。它是深度学习的基础，能够学习复杂的非线性映射关系。

## 生物神经元与人工神经元

### 生物神经元结构
- **树突**：接收来自其他神经元的信号
- **细胞体**：处理信息
- **轴突**：输出信号
- **突触**：神经元之间的连接点

### 人工神经元模型（MP模型）

1943年，McCulloch和Pitts提出的数学模型：

```
y = f(Σ(wᵢ × xᵢ) + b)

其中：
xᵢ：输入信号
wᵢ：连接权重
b：偏置（阈值）
f：激活函数
y：输出
```

## 神经网络的基本结构

### 层（Layer）

#### 输入层（Input Layer）
- 接收原始数据
- 神经元数量等于输入特征维度
- 不进行计算，仅传递数据

#### 隐藏层（Hidden Layer）
- 进行特征提取和变换
- 可以有多层（深度学习的"深度"来源）
- 每层包含多个神经元

#### 输出层（Output Layer）
- 产生最终预测结果
- 神经元数量等于输出类别数或回归值维度
- 激活函数根据任务类型选择

### 网络拓扑结构

```
    ○      <- 输入层神经元
   /|\
  / | \
 ○  ○  ○   <- 隐藏层1
 |\ | /|
 | \|/ |
 ○  ○  ○   <- 隐藏层2
  \ | /
   \|/
    ○      <- 输出层
```

## 神经网络的类型

### 1. 前馈神经网络（Feedforward Neural Network）

信息单向传播，无循环连接。

#### 全连接神经网络（FCNN/MLP）
- 每层神经元与下一层全部连接
- 最基础的神经网络架构
- 适用于结构化数据

**前向传播公式**：
```
z^[l] = W^[l]a^[l-1] + b^[l]
a^[l] = g(z^[l])
```

### 2. 卷积神经网络（CNN）

专门用于处理具有网格结构的数据（如图像）。

#### 核心组件

**卷积层（Convolutional Layer）**：
```
输出特征图 = 输入特征图 ⊛ 卷积核 + 偏置
```
- 局部连接：每个神经元只连接局部区域
- 权重共享：同一卷积核在整个输入上滑动
- 平移不变性：能够识别不同位置的特征

**池化层（Pooling Layer）**：
- 最大池化（Max Pooling）：取窗口内最大值
- 平均池化（Average Pooling）：取窗口内平均值
- 作用：降维、减少计算量、提供平移不变性

**全连接层（Fully Connected Layer）**：
- 将特征图展平后进行分类
- 通常位于网络末端

#### 经典架构演进

| 年份 | 模型 | 创新点 |
|-----|------|-------|
| 1998 | LeNet-5 | 首个成功应用的CNN |
| 2012 | AlexNet | ReLU+Dropout，开启深度学习时代 |
| 2014 | VGGNet | 小卷积核(3×3)堆叠 |
| 2014 | GoogLeNet | Inception模块 |
| 2015 | ResNet | 残差连接，可训练152+层 |
| 2016 | DenseNet | 密集连接 |
| 2019 | EfficientNet | 复合缩放，效率最优 |

### 3. 循环神经网络（RNN）

用于处理序列数据，具有内部记忆机制。

#### 基本RNN
```
hₜ = tanh(Wₕₕ × hₜ₋₁ + Wₓₕ × xₜ + b)
yₜ = Wₕᵧ × hₜ + bᵧ
```

其中hₜ是隐藏状态，保存了序列的历史信息。

#### 长短期记忆网络（LSTM）

解决RNN的长期依赖问题，通过门控机制控制信息流。

**门控结构**：
```
遗忘门：fₜ = σ(Wf · [hₜ₋₁, xₜ] + bf)
输入门：iₜ = σ(Wi · [hₜ₋₁, xₜ] + bi)
输出门：oₜ = σ(Wo · [hₜ₋₁, xₜ] + bo)

细胞状态：Cₜ = fₜ ⊙ Cₜ₋₁ + iₜ ⊙ C̃ₜ
隐藏状态：hₜ = oₜ ⊙ tanh(Cₜ)
```

#### 门控循环单元（GRU）

LSTM的简化版本，合并细胞状态和隐藏状态。

```
更新门：zₜ = σ(Wz · [hₜ₋₁, xₜ])
重置门：rₜ = σ(Wr · [hₜ₋₁, xₜ])

候选状态：h̃ₜ = tanh(W · [rₜ ⊙ hₜ₋₁, xₜ])
新状态：hₜ = (1 - zₜ) ⊙ hₜ₋₁ + zₜ ⊙ h̃ₜ
```

### 4. Transformer架构

基于注意力机制的序列模型，当前NLP和视觉任务的主流架构。

#### 自注意力机制（Self-Attention）

```
Attention(Q, K, V) = softmax(QKᵀ / √dₖ) V

其中：
Q = XW^Q  (Query)
K = XW^K  (Key)
V = XW^V  (Value)
```

**计算步骤**：
1. 计算Query、Key、Value
2. 计算注意力分数：Q × Kᵀ
3. 缩放：除以√dₖ
4. Softmax归一化
5. 加权求和：与Value相乘

#### 多头注意力（Multi-Head Attention）

```
MultiHead(Q, K, V) = Concat(head₁, ..., headₕ)W^O

where headᵢ = Attention(QWᵢ^Q, KWᵢ^K, VWᵢ^V)
```

#### Transformer完整架构

**编码器（Encoder）**：
- 多头自注意力
- 前馈网络
- 层归一化
- 残差连接

**解码器（Decoder）**：
- 掩码多头自注意力
- 编码器-解码器注意力
- 前馈网络
- 层归一化
- 残差连接

## 神经网络的训练

### 损失函数

#### 回归任务
- **均方误差（MSE）**：
  ```
  L = (1/n) Σ(yᵢ - ŷᵢ)²
  ```

- **平均绝对误差（MAE）**：
  ```
  L = (1/n) Σ|yᵢ - ŷᵢ|
  ```

#### 分类任务
- **交叉熵损失（Cross-Entropy）**：
  ```
  L = -Σ yᵢ log(ŷᵢ)
  ```

- **二元交叉熵**：
  ```
  L = -[y log(ŷ) + (1-y) log(1-ŷ)]
  ```

### 优化算法

#### 梯度下降变体

**批量梯度下降**：
```
θ = θ - η · ∇J(θ)
```

**随机梯度下降（SGD）**：
```
θ = θ - η · ∇J(θ; x⁽ⁱ⁾, y⁽ⁱ⁾)
```

**小批量梯度下降**：
```
θ = θ - η · ∇J(θ; x⁽ⁱⁱ⁺ᵐ⁾, y⁽ⁱⁱ⁺ᵐ⁾)
```

#### 自适应优化器

**Adam（Adaptive Moment Estimation）**：
```
mₜ = β₁mₜ₋₁ + (1-β₁)gₜ
vₜ = β₂vₜ₋₁ + (1-β₂)gₜ²

m̂ₜ = mₜ / (1-β₁ᵗ)
v̂ₜ = vₜ / (1-β₂ᵗ)

θₜ = θₜ₋₁ - η · m̂ₜ / (√v̂ₜ + ε)
```

### 训练技巧

1. **学习率调度**
   - Step Decay：每隔一定步数降低学习率
   - Exponential Decay：指数衰减
   - Cosine Annealing：余弦退火

2. **早停（Early Stopping）**
   - 监控验证集性能
   - 性能不再提升时停止训练

3. **数据增强**
   - 图像：翻转、旋转、裁剪、色彩变换
   - 文本：同义词替换、回译

4. **批量归一化（Batch Normalization）**
   - 加速训练
   - 允许使用更大学习率
   - 具有正则化效果
