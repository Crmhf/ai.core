# RAG检索增强生成

## 概述

RAG（Retrieval-Augmented Generation）通过“检索外部知识 + 大模型生成”提升回答准确性，特别适用于企业知识库问答、客服、合规检索等场景。

## 核心架构

```
用户问题 → 查询改写 → 向量检索/混合检索 → 重排序 → 上下文构建 → LLM生成 → 引用返回
```

## 关键模块

### 1. 文档处理
- 切分策略：按段落、语义、滑动窗口
- 向量化：Embedding模型编码
- 索引构建：向量索引 + 元数据索引

### 2. 检索策略
- 稠密检索：向量相似度
- 稀疏检索：BM25关键词匹配
- 混合检索：兼顾语义与关键字精确度

### 3. 重排序与生成
- Cross-Encoder重排序提升相关性
- 通过系统提示限制“只基于检索内容回答”
- 输出引用来源降低幻觉风险

## 评估指标
- Recall@K、MRR、nDCG
- 答案正确率与可追溯率
- 用户满意度与首问解决率

## 常见问题
- 召回不足：切分粒度或向量模型不匹配
- 噪声过多：需要重排序和过滤
- 多跳问题：需引入查询分解与多轮检索

## 发展方向
- Agentic RAG：自主查询与工具调用
- 图RAG：结合知识图谱进行结构化推理
- 多模态RAG：文本、图像、音视频联合检索
