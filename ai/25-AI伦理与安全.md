# AI伦理与安全

## 概述

随着人工智能技术的快速发展和广泛应用，AI伦理与安全问题日益凸显。从算法偏见到隐私侵犯，从深度伪造到自主武器，AI技术带来的风险和挑战需要全社会的关注和应对。建立负责任的AI发展框架，确保AI技术安全、可靠、可控，是当前AI治理的核心议题。

## AI伦理核心议题

### 1. 公平性与偏见

#### 偏见来源
```
数据偏见：
- 历史数据中的系统性偏差
- 采样偏差
- 标注偏见

算法偏见：
- 模型设计中的隐性假设
- 优化目标单一
- 反馈循环放大偏见

部署偏见：
- 不同群体的使用差异
- 上下文适配不足
```

#### 典型案例
| 案例 | 描述 | 影响 |
|-----|------|------|
| 招聘AI偏见 | 亚马逊招聘系统对女性有偏见 | 性别歧视 |
| 司法风险评估 | COMPAS系统对少数族裔评分更高 | 种族不平等 |
| 面部识别 | 对深色皮肤人群准确率更低 | 歧视性执法 |
| 信贷审批 | 某些地区被拒率异常高 | 经济排斥 |

#### 缓解措施
- **多样化数据集**：确保代表性
- **公平性指标**：统计平等、机会均等
- **公平性约束**：训练中加入公平性约束
- **可解释性**：识别偏见来源
- **持续监测**：部署后偏见检测

### 2. 隐私保护

#### 隐私风险
```
数据收集阶段：
- 过度收集
- 不透明授权

模型训练阶段：
- 数据记忆
- 成员推断攻击

模型推理阶段：
- 输入隐私
- 模型反演

模型共享阶段：
- 模型提取
- 参数泄露
```

#### 隐私保护技术
| 技术 | 原理 | 应用 |
|-----|------|------|
| 差分隐私 | 添加噪声保护个体 | 数据发布、模型训练 |
| 联邦学习 | 数据不出本地 | 跨机构协作 |
| 同态加密 | 加密状态下计算 | 隐私推理 |
| 安全多方计算 | 多方联合计算 | 隐私求交、建模 |
| 数据脱敏 | 匿名化、假名化 | 数据共享 |

### 3. 透明度与可解释性

#### 可解释性层次
```
模型层面：
- 模型结构可解释（决策树、线性模型）
- 事后解释（SHAP、LIME）

决策层面：
- 单个预测的解释
- 反事实解释

系统层面：
- 整体行为说明
- 设计意图文档
```

#### 可解释性方法
| 方法 | 类型 | 适用 |
|-----|------|------|
| SHAP | 特征重要性 | 模型无关 |
| LIME | 局部近似 | 模型无关 |
| Attention | 注意力可视化 | Transformer |
| Grad-CAM | 梯度热力图 | CNN |
| 概念激活向量 | 概念级别解释 | 深度学习 |

### 4. 责任与问责

#### 责任归属困境
```
AI系统决策导致损害时，谁负责？
- 开发者：设计缺陷？
- 部署者：使用不当？
- 用户：误用？
- 系统本身？
```

#### 解决方向
- **人机协同决策**：关键决策人类把关
- **审计追踪**：决策日志记录
- **责任保险**：AI责任险
- **法律框架**：明确责任主体

### 5. 自主性与人类控制

#### 自主程度分级
| 级别 | 描述 | 示例 |
|-----|------|------|
| 辅助 | AI提供建议，人类决策 | 推荐系统 |
| 监督 | AI自主运行，人类监督 | 自动驾驶L2 |
| 条件自主 | 特定条件下完全自主 | 自动驾驶L3 |
| 高度自主 | 人类仅在必要时介入 | 自动驾驶L4 |
| 完全自主 | 无需人类干预 | 自动化工厂 |

#### 人类控制原则
- **有意义的人类控制**：关键决策人类把关
- **人类在环(Human-in-the-loop)**：实时监督
- **人类 on the loop**：事后审查
- **紧急停止**：随时可干预

## AI安全威胁

### 1. 对抗攻击

#### 攻击类型
```
白盒攻击：
- 攻击者知道模型结构参数
- FGSM、PGD、C&W

黑盒攻击：
- 仅能通过输入输出攻击
- 迁移攻击、查询攻击

物理世界攻击：
- 对抗补丁
- 对抗物体
- 对抗眼镜
```

#### 防御方法
- **对抗训练**：在训练中加入对抗样本
- **输入净化**：检测/去除对抗噪声
- **防御蒸馏**：模型鲁棒性增强
- **认证防御**：可证明的鲁棒性

### 2. 数据投毒

#### 攻击方式
```
训练数据投毒：
- 注入恶意样本
- 标签翻转
- 后门攻击

模型供应链攻击：
- 预训练模型植入后门
- 开源模型篡改
```

#### 防御措施
- 数据验证和清洗
- 训练过程监控
- 模型审计
- 供应链安全

### 3. 模型窃取

#### 攻击手段
- **查询攻击**：大量查询重建模型
- **侧信道攻击**：利用时间、功耗信息
- **模型提取**：从API提取模型功能

#### 防护策略
- 查询限制和监控
- 输出扰动
- 水印技术
- 法律手段

### 4. 深度伪造(Deepfake)

#### 技术原理
- GAN生成逼真内容
- 人脸替换、表情迁移
- 语音克隆

#### 风险
- 虚假信息传播
- 身份冒用
- 政治操纵
- 色情内容

#### 检测与治理
- 深度伪造检测算法
- 数字水印
- 内容溯源
- 法律法规

### 5. AI武器化

#### 自主武器系统
```
致命性自主武器系统(LAWS)：
- 无需人类干预选择目标
- 引发人道主义关切

争议焦点：
- 道德责任
- 区分原则（战斗员/平民）
- 比例原则
- 人道关切
```

#### 国际治理
- 联合国《特定常规武器公约》讨论
- 各国政策差异
- 民间社会呼吁禁止

#### 主要倡议

|----------|----------|---------|

| G20 | AI原则 | 经济议题 |

#### 欧盟AI法案
```
风险分级：
- 不可接受风险：禁止（社会信用评分、操纵）
- 高风险：严格监管（关键基础设施、教育、就业）
- 有限风险：透明度义务（聊天机器人）
- 最小风险：自愿准则（游戏AI）

要求：
- 风险管理系统
- 数据治理
- 技术文档
- 记录保存
- 透明度
- 人工监督
- 准确性和鲁棒性
```
