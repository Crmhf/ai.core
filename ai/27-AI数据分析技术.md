# AI数据分析技术

## 概述

人工智能正在革命性地改变数据分析的方式，从传统的描述性分析向预测性分析和规范性分析演进。AI技术能够处理海量数据、发现复杂模式、自动生成洞察，并支持更智能的决策。2024年，大模型与数据分析的融合（如ChatBI）成为重要趋势。

### 3. 大模型+数据分析

#### Text2SQL/Text2Code
```
用户问："对比北京和上海上季度各品类的销售额"

AI生成：
```python
import pandas as pd

# 筛选数据
beijing = df[(df['city']=='北京') & (df['quarter']=='Q3')]
shanghai = df[(df['city']=='上海') & (df['quarter']=='Q3')]

# 分组统计
bj_sales = beijing.groupby('category')['sales'].sum()
sh_sales = shanghai.groupby('category')['sales'].sum()

# 对比可视化
comparison = pd.DataFrame({'北京': bj_sales, '上海': sh_sales})
comparison.plot(kind='bar')
```

代表产品：
- ChatGPT Code Interpreter
- GitHub Copilot Chat
- 自然堂问数GPT
```
