# 强化学习

## 概述

强化学习（Reinforcement Learning，RL）是机器学习的重要分支，研究智能体如何在环境中通过试错来学习最优行为策略，以最大化累积奖励。从AlphaGo击败世界围棋冠军到ChatGPT的RLHF训练，强化学习正在推动人工智能的边界。

## 核心概念

### 基本要素

```
┌─────────────────────────────────────────┐
│              强化学习系统                │
├─────────────────────────────────────────┤
│  智能体(Agent) ←──动作(a)──→ 环境(Environment)│
│       ↑                          │      │
│       └────────状态(s)───────────┘      │
│              ↑                          │
│              └────────奖励(r)───────────┘
└─────────────────────────────────────────┘
```

| 要素 | 符号 | 说明 |
|-----|------|------|
| 状态(State) | s ∈ S | 环境在某一时刻的描述 |
| 动作(Action) | a ∈ A | 智能体可执行的操作 |
| 奖励(Reward) | r ∈ R | 环境对动作的即时反馈 |
| 策略(Policy) | π(a\|s) | 状态到动作的映射 |
| 状态转移 | p(s'\|s,a) | 执行动作后环境的变化 |

### 回报与折扣

#### 累积回报
```
G_t = R_{t+1} + R_{t+2} + R_{t+3} + ... + R_T

折扣回报（考虑未来奖励的不确定性）：
G_t = R_{t+1} + γR_{t+2} + γ²R_{t+3} + ... = Σ γ^k R_{t+k+1}

γ: 折扣因子 (0 ≤ γ ≤ 1)
   - γ=0: 只考虑即时奖励
   - γ=1: 平等对待所有未来奖励
   - 通常取0.9-0.99
```

### 价值函数

#### 状态价值函数 V(s)
```
从状态s开始，遵循策略π的期望回报：
V^π(s) = E^π[G_t | S_t = s]

表示某个状态有多好
```

#### 动作价值函数 Q(s,a)
```
在状态s下执行动作a，然后遵循策略π的期望回报：
Q^π(s,a) = E^π[G_t | S_t = s, A_t = a]

表示某个状态下某个动作有多好
```

#### 贝尔曼方程
```
V(s) = Σ π(a|s) Σ p(s',r|s,a)[r + γV(s')]

当前状态的价值 = 即时奖励 + 折扣后的下一状态价值

Q(s,a) = Σ p(s',r|s,a)[r + γ max_a' Q(s',a')]
```

## 主要算法

### 1. 基于值函数的方法

#### Q-Learning
```
最经典的强化学习算法之一

更新规则：
Q(s,a) ← Q(s,a) + α[r + γ max_a' Q(s',a') - Q(s,a)]

其中：
- α: 学习率
- γ: 折扣因子
- max_a' Q(s',a'): 下一状态的最大Q值

特点：
- 离策略(Off-policy)
- 可以学习最优策略同时采用探索策略
```

#### SARSA
```
On-policy版本的时序差分控制

更新规则：
Q(s,a) ← Q(s,a) + α[r + γ Q(s',a') - Q(s,a)]

与Q-Learning区别：
- Q-Learning使用max（乐观估计）
- SARSA使用实际采取的a'（保守估计）
```

#### DQN（Deep Q-Network）
```
将深度学习与Q-Learning结合

关键技术：
1. 经验回放(Experience Replay)
   - 存储(s,a,r,s')到回放缓冲区
   - 随机采样打破数据相关性

2. 目标网络(Target Network)
   - 单独的网络计算目标Q值
   - 定期同步，提高稳定性

损失函数：
L = (r + γ max_a' Q_target(s',a') - Q(s,a))²
```

#### 改进版本
```
Double DQN: 解决Q值过估计
Dueling DQN: 分离状态价值和优势函数
Prioritized Experience Replay: 优先采样重要经验
Noisy Nets: 参数化探索
C51/Rainbow: 分布式RL
```

### 2. 基于策略的方法

#### 策略梯度(Policy Gradient)
```
直接参数化策略 π_θ(a|s)

目标：最大化期望回报
J(θ) = E[Σ r | π_θ]

梯度：
∇_θ J(θ) = E[∇_θ log π_θ(a|s) · G_t]

直观理解：
- 好轨迹（高回报）增加概率
- 坏轨迹（低回报）减少概率
```

#### REINFORCE算法
```
蒙特卡洛策略梯度

流程：
1. 根据当前策略采样完整轨迹
2. 计算轨迹回报G
3. 更新参数：θ ← θ + α G ∇_θ log π_θ(a|s)

缺点：
- 高方差
- 需要完整轨迹
```

#### Actor-Critic
```
结合值函数和策略梯度

结构：
- Actor（策略网络）：决定动作
- Critic（价值网络）：评估动作

优势：
- Critic提供baseline，降低方差
- 可以在线学习（不需要完整轨迹）

A2C (Advantage Actor-Critic):
使用优势函数 A(s,a) = Q(s,a) - V(s)
```

### 3. 高级算法

#### PPO (Proximal Policy Optimization)
```
OpenAI提出的稳定策略优化算法

核心思想：
- 限制策略更新幅度
- 避免破坏性大更新

目标函数：
L^CLIP(θ) = E[min(r_t(θ)A_t, clip(r_t(θ), 1-ε, 1+ε)A_t)]

其中 r_t(θ) = π_θ(a|s) / π_θ_old(a|s) 是重要性采样比率

特点：
- 实现简单
- 超参数不敏感
- 样本效率较高
- 当前最常用算法之一
```

#### SAC (Soft Actor-Critic)
```
最大熵强化学习

目标：
最大化回报 + 策略熵（鼓励探索）

特点：
- Off-policy，样本效率高
- 自动调节温度参数
- 对超参数鲁棒
```

#### DDPG (Deep Deterministic Policy Gradient)
```
确定性策略梯度的深度版本

适用场景：
- 连续动作空间

结构：
- Actor: 输出确定性动作
- Critic: 评估Q值

技巧：
- 软更新（Soft Update）
- Ornstein-Uhlenbeck噪声
```

#### TD3 (Twin Delayed DDPG)
```
DDPG的改进版本

改进点：
1. 双Q网络（减少过估计）
2. 延迟策略更新
3. 目标策略平滑
```

## 多智能体强化学习

### 问题类型

| 类型 | 描述 | 示例 |
|-----|------|------|
| 合作型 | 智能体共同最大化团队奖励 | 机器人协作 |
| 竞争型 | 零和博弈 | 围棋、扑克 |
| 混合型 | 既有合作又有竞争 | 足球比赛 |

### MADDPG
```
多智能体DDPG

特点：
- 每个智能体有自己的Critic
- Critic可以看到全局信息
- Actor只能看到局部观测
```

## 挑战与前沿

### 主要挑战

#### 1. 样本效率
```
问题：需要大量交互数据

解决方案：
- 模型-based方法（学习环境模型）
- 模仿学习
- 迁移学习
- 离线强化学习
```

#### 2. 奖励设计
```
问题：
- 稀疏奖励
- 奖励塑形困难
- 奖励黑客

解决方案：
- 课程学习
- 分层强化学习
- 逆强化学习
```

#### 3. 泛化能力
```
问题：训练环境到真实环境的迁移

解决方案：
- 域随机化
- 模拟到现实(Sim-to-Real)
- 元强化学习
```

#### 4. 安全性
```
问题：探索过程可能危险

解决方案：
- 约束强化学习
- 安全探索
- 人类监督
```

### 前沿方向

#### 1. 离线强化学习(Offline RL)
- 从固定数据集学习
- 无需环境交互
- 实际应用更安全

#### 2. 模型预测控制(MPC) + RL
- 结合模型预测和强化学习
- 提高样本效率

#### 3. 分层强化学习
- 高层策略+低层策略
- 解决长期任务

#### 4. 多任务与元学习
- 快速适应新任务
- 知识迁移
