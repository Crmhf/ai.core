# 自动驾驶技术

## 概述

自动驾驶是利用人工智能、传感器融合、高精度地图等技术，使车辆能够在无需人类干预的情况下安全行驶。2024年被认为是自动驾驶的关键转折点，L3级自动驾驶进入量产爆发期，端到端大模型成为主流技术路线。

## 自动驾驶分级标准

### SAE国际标准

| 级别 | 名称 | 定义 | 人类角色 |
|-----|------|------|---------|
| L0 | 无自动化 | 完全人工驾驶 | 全程控制 |
| L1 | 驾驶辅助 | 单一功能辅助（如巡航） | 监控并随时接管 |
| L2 | 部分自动化 | 组合功能辅助（如ACC+LKA） | 监控并随时接管 |
| L3 | 有条件自动化 | 特定条件下自动驾驶 | 需要时接管 |
| L4 | 高度自动化 | 限定区域无人驾驶 | 无需驾驶（限定区域） |
| L5 | 完全自动化 | 全场景无人驾驶 | 无需驾驶 |

### 2024年进展
- **L2+**：高速NOA普及，城市NOA铺开
- **L3**：多国批准上路，奔驰、宝马、华为等量产
- **L4**：Robotaxi在特定区域商业化运营

## 核心技术架构

### 1. 感知系统

#### 传感器配置

**多传感器融合方案**：
```
摄像头：
- 数量：6-12个
- 功能：目标识别、车道线检测、交通标志
- 优势：信息丰富、成本低
- 劣势：受光照影响

激光雷达：
- 数量：1-4个（部分方案无）
- 功能：3D环境建模、精确测距
- 优势：精度高、全天候
- 劣势：成本高、恶劣天气受影响

毫米波雷达：
- 数量：3-5个
- 功能：测速、测距、穿透雨雾
- 优势：全天候、测速准确
- 劣势：分辨率低

超声波雷达：
- 数量：8-12个
- 功能：近距离泊车
- 优势：成本低
- 劣势：范围短
```

#### 视觉感知技术

**BEV（鸟瞰图）感知**：
- 将多摄像头数据转换到统一鸟瞰视角
- Transformer架构实现
- 更好空间理解能力

**Occupancy Network**：
- 3D占据栅格网络
- 不依赖物体类别，通用障碍物检测
- 提升异形障碍物识别能力

### 2. 定位与地图

#### 高精度定位
- **GNSS+RTK**：厘米级定位
- **IMU**：惯性测量，短时高精度
- **轮速计**：里程计信息
- **视觉定位**：特征匹配
- **激光定位**：点云匹配

#### 高精度地图(HD Map)
- 厘米级精度
- 包含车道线、交通标志、坡度等
- 众包更新

**趋势**：
- 重感知、轻地图
- 在线建图（SD Map + 实时感知）

### 3. 决策规划

#### 分层架构
```
全局规划层：
- 路径规划（Route Planning）
- 基于地图和导航

行为决策层：
- 行为预测
- 决策逻辑（跟车、换道、超车）

运动规划层：
- 轨迹规划（Trajectory Planning）
- 速度规划
- 约束满足（安全、舒适、效率）
```

#### 决策方法

**规则-based**：
- 状态机
- 行为树
- 有限状态机

**学习-based**：
- 模仿学习
- 强化学习
- 端到端学习

### 4. 控制执行

#### 横向控制
- **纯追踪控制(Pure Pursuit)**
- **Stanley控制**
- **MPC（模型预测控制）**

#### 纵向控制
- **PID控制**
- **ACC控制**
- **碰撞避免**

## 2024年技术突破：端到端大模型

### 什么是端到端

**传统方案**：
```
感知 → 定位 → 预测 → 决策 → 规划 → 控制
（模块独立，人工设计接口）
```

**端到端方案**：
```
传感器数据 → 神经网络 → 控制输出
（直接学习驾驶行为）
```

## AI核心技术

### 1. 深度学习在感知中的应用

#### 目标检测
- **YOLO系列**：实时检测
- **CenterNet**：anchor-free检测
- **DETR**：基于Transformer

#### 语义分割
- **U-Net**：精确分割
- **DeepLab**：多尺度特征
- **SegFormer**：高效Transformer分割

#### 3D目标检测
- **PointNet/PointNet++**：点云处理
- **VoxelNet**：体素化表示
- **PointPillars**：快速3D检测
- **BEVFormer**：BEV视角检测

### 2. 预测与决策AI

#### 行为预测
- **LSTM**：轨迹预测
- **Social LSTM**：交互建模
- **Transformer**：多模态预测
- **GNN**：图神经网络建模交互

#### 强化学习
- **DQN**：价值学习
- **DDPG**：连续控制
- **PPO**：策略优化
- **MADDPG**：多智能体决策

### 3. 世界模型(World Model)

**概念**：
- 构建环境的内部表示
- 预测未来状态
- 用于规划和仿真

**代表**：
- **Waymo**的仿真系统
- **蔚来NWM**
- **理想世界模型**
- **英伟达Cosmos**

- 景区观光

## 挑战与问题

### 技术挑战

#### 长尾场景
- 极端天气（暴雨、大雪、浓雾）
- 异形障碍物
- 复杂交通博弈
- 施工路段

#### 安全性
- 功能安全(ISO 26262)
- 预期功能安全(SOTIF)
- 网络安全
- 数据安全

### 商业挑战
- **成本高**：传感器、计算平台
- **法规滞后**：责任认定、保险制度
- **公众接受度**：信任建立
