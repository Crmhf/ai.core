# GPU与NPU技术

## 概述

GPU（图形处理器）和NPU（神经网络处理器）是当前AI计算的两类核心芯片。GPU凭借强大的并行计算能力和成熟的软件生态主导训练市场，NPU则以高能效比优势在边缘和终端AI推理中快速普及。

## GPU技术详解

### GPU架构演进

#### 1. 传统GPU架构
```
图形流水线：
顶点处理 → 图元装配 → 光栅化 → 片元处理 → 帧缓冲

计算扩展：
通用计算单元（CUDA Core）取代专用图形单元
```

#### 2. 现代GPU架构（以NVIDIA为例）

**Ampere架构**：
- 第三代Tensor Core
- 结构化稀疏性加速
- MIG（多实例GPU）

**Hopper架构**：
- 第四代Tensor Core
- Transformer Engine
- NVLink 4.0
- H100数据中心GPU

**Blackwell架构（2024）**：
- 第五代Tensor Core
- AI性能大幅提升
- 新一代数据中心GPU

### GPU计算核心

#### CUDA Core
```
基础计算单元：
- 浮点运算（FP32/FP64）
- 整数运算
- 每个SM包含多个CUDA Core

SM（Streaming Multiprocessor）：
- GPU的基本计算模块
- 包含CUDA Core、Tensor Core、寄存器文件等
```

#### Tensor Core
```
专门用于矩阵运算：
- 混合精度计算
- 4x4x4矩阵乘法累加
- 每代性能翻倍

精度支持：
- FP64/FP32/TF32
- FP16/BF16
- INT8/INT4
- FP8（Hopper+）
```

### GPU内存架构

#### GDDR vs HBM

| 特性 | GDDR6/X | HBM2E/3 |
|-----|---------|---------|
| 位宽 | 32-bit | 1024-bit |
| 容量 | 单颗16-24GB | 单堆16-24GB |
| 带宽 | 64-112 GB/s | 460-819 GB/s |
| 功耗 | 较高 | 较低 |
| 成本 | 较低 | 较高 |
| 应用 | 消费级GPU | 数据中心GPU |

#### 统一内存(Unified Memory)
```
特性：
- CPU和GPU共享虚拟地址空间
- 自动数据迁移
- 简化编程

应用：
- 大模型训练
- 超大数据集处理
```

### GPU互联技术

#### NVLink
```
NVIDIA专有高速互联：
- NVLink 3.0：50 GB/s每链路
- NVLink 4.0：100 GB/s每链路
- GPU间直连

NVSwitch：
- 全互联拓扑
- 支持16+ GPU全连接
```

#### NVLink vs PCIe

| 特性 | NVLink | PCIe 5.0 |
|-----|--------|----------|
| 带宽 | 100 GB/s | 64 GB/s |
| 延迟 | 更低 | 较高 |
| 拓扑 | 灵活 | 树形 |
| 应用 | GPU集群 | 通用扩展 |

## NPU技术详解

### NPU架构特点

#### 专用AI加速
```
区别于GPU的通用性：
- 针对神经网络算子优化
- 定点运算为主
- 超高能效比

核心组件：
- MAC阵列（乘加单元）
- 专用激活函数单元
- 片上缓存优化
```

#### 数据流优化
```
Weight Stationary：
- 权重保存在片上
- 最大化权重复用

Output Stationary：
- 累加结果保存在片上
- 减少内存访问

Row Stationary：
- 平衡权重和激活复用
```

## GPU与NPU协同

### 异构计算架构
```
┌─────────────────────────────────────┐
│           异构AI计算架构             │
├─────────────┬───────────┬───────────┤
│    CPU      │   GPU     │   NPU     │
├─────────────┼───────────┼───────────┤
│ 逻辑控制    │ 大规模并行 │ 高效AI推理 │
│ 通用任务    │ 训练/复杂推理│ 轻量AI任务 │
│ 系统管理    │ 图形渲染  │ 常驻AI功能 │
└─────────────┴───────────┴───────────┘
```

### 任务分配策略

| 任务类型 | 推荐处理器 | 原因 |
|---------|-----------|------|
| 大模型训练 | GPU | 高算力、大显存 |
| 大模型推理(大batch) | GPU | 吞吐量大 |
| 大模型推理(小batch) | GPU/NPU | 延迟要求 |
| 常驻AI功能 | NPU | 低功耗、Always-on |
| 轻量级AI | NPU | 能效最优 |
| 复杂AI流水线 | GPU+NPU协同 | 分工优化 |

## 性能优化技术

### 1. 混合精度
```
FP32 + FP16/INT8：
- 训练：FP32主权重 + FP16计算
- 推理：INT8量化
- 3-4倍加速，精度损失小
```

### 2. 模型量化
| 精度 | 相对FP32加速 | 精度损失 | 应用 |
|-----|-------------|---------|------|
| FP16 | 2x | 极小 | 训练/推理 |
| INT8 | 4x | 小 | 通用推理 |
| INT4 | 8x | 中等 | 端侧推理 |

### 3. 剪枝与稀疏
- **结构化剪枝**：移除整个通道
- **非结构化剪枝**：移除单个权重
- **稀疏加速**：利用硬件稀疏支持

### 4. 编译优化
- **算子融合**：减少内存访问
- **内存布局优化**：提高缓存命中率
- **并行优化**：最大化硬件利用率
