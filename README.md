## 📰 AI 垂类行业日报（`daily/`）

**自动化追踪 AI 行业最新动态**，每日生成结构化报告并提交到 GitHub。

### 日报内容结构
- **今日概览** — 行业整体态势摘要
- **重点关注** — 3-6 条核心新闻深度分析
- **深度分析** — 技术与市场趋势解读
- **行业动态** — 技术趋势 + 市场动态
- **明日关注** — 后续跟踪建议
- **参考资料** — 权威信息来源

### 自动化流程
```
定时触发（每天 08:00 CST）
    ↓
AI 分析师执行 web_search 收集资讯
    ↓
生成结构化 Markdown 报告
    ↓
git commit & push 到本仓库
    ↓
报告送达
```

## 📊 2026 智能体编程趋势研究（`doc/`）

基于行业观察的深度研究报告，提出 **8 大核心趋势**：

| # | 趋势 | 类别 |
|---|------|------|
| 1 | 软件开发生命周期剧变 | 基础趋势 |
| 2 | 单一智能体进化为协调团队 | 能力趋势 |
| 3 | 长期运行智能体构建完整系统 | 能力趋势 |
| 4 | 人机监督通过智能协作扩展 | 能力趋势 |
| 5 | 智能体编程扩展到新领域和用户 | 能力趋势 |
| 6 | 生产力提升重塑软件开发经济学 | 影响趋势 |
| 7 | 非技术用例扩展到整个组织 | 影响趋势 |
| 8 | 双重用途风险需要安全优先架构 | 影响趋势 |

**核心洞察**：开发者在约 60% 的工作中使用 AI，但能够"完全委托"的任务仅占 0-20% —— 智能体编程的本质是**高度协作而非完全替代**。

## 🎮 实践 Demo（`demo/`）

### 射击游戏（`demo/gun/`）
完整的 HTML5 射击游戏，包含：
- **游戏引擎**：地图系统、物理碰撞、粒子效果
- **AI 敌人**：基于状态机的敌人行为（巡逻、追击、攻击）

## 🚀 快速开始

### 克隆仓库
```bash
git clone git@github.com:Crmhf/ai.core.git
cd ai.core
```

### 阅读知识百科
```bash
cat ai/01-AI概述与历史发展.md
cat ai/35-AI Agent架构设计.md
```

### 运行射击游戏 Demo
```bash
cd demo/gun && python3 -m http.server 8000
# 访问 http://localhost:8000
```

### 生成日报（手动触发）
```bash
# 使用 Hermes Agent 定时任务
hermes cron run ai-daily-report
```
